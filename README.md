# Kanboto starters

Blueprint apps for [Kanboto](https://kanboto.com) : un projet minimal par stack, qui respecte tous les
standards que Kanboto vérifie sur les repos qu'il pilote. Kanboto s'en sert comme point de départ des
squelettes, et ce repo sert de banc d'essai à ses kits CI.

| Stack | Dossier |
|---|---|
| FastAPI (Python) | [`fastapi/`](fastapi/) |

Chaque starter porte son `AGENTS.md` (règles lues par les agents, section tenue par Kanboto) et son kit CI
Kanboto dans `.github/workflows/`.
